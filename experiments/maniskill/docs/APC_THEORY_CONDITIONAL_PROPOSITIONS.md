## 1. 理論化の背景と前提

Adaptive Primitive Consolidation (APC) の実験フェーズ（W0〜W7）において、局所小型決定木（CART）による補正、モデルファイルの切り離し（39.8 KB配布物）、同一ルーターでのアブレーション、および課題列での初期的な過去課題実行が試行された。
一方で、未学習の目標座標におけるタイムアウト、手設計回復ガードへの依存、ルーター学習データとの重複など、多くの適用境界と検証課題が確認された。

本稿（W8 / T23）の目的は、実験の成功例を無条件に一般化するのではなく、**「どのような前提条件（Assumptions）が揃えば特定の性質が導かれ、現行の実装・実測がどこまでその前提を満たしているか」** を客観的かつ厳密に定式化・検証することである。

## 2. 命題 1：局所非介入における行動不変性と保持の条件（Invariance Under Local Non-Intervention）

### 2.1 前提仮定（Assumptions）
- **仮定 1.1（基盤方策および既存モジュールの不変性）**:
  - 基盤方策 $\pi_{\text{base}}$、既存の局所 Candidate 群 $\{\pi_i\}_{i \in \text{past}}$、観測特徴量変換 $\phi(s)$、および低位実行器は、新モジュール $\pi_{\text{new}}$ 追加時にも完全に凍結（Frozen）されている。
- **仮定 1.2（決定論的環境と同一乱数系列）**:
  - 物理環境は同一初期状態 $s_0 \sim \mathcal{D}_{\text{past}}$ および同一乱数シードのもとで決定論的に遷移する。
- **仮定 1.3（旧タスク軌跡上での非介入かつルーティング不変）**:
  - 過去タスク $\mathcal{T}_{\text{past}}$ の誘発する軌跡分布 $\mathcal{D}_{\text{past}}$ 上において、更新後のルーター $R_{\text{new}}(s)$ が新モジュールを選択する確率が 0 であるだけでなく、**既存モジュール間（Base と既存 Candidate 間）のルーティング結果も完全に更新前と一致する**：
    $$\forall s \in \mathcal{D}_{\text{past}}, \quad R_{\text{new}}(s) = R_{\text{old}}(s)$$

### 2.2 命題の主張（Proposition 1）
上記の仮定 1.1〜1.3 が厳密に満たされるならば、新モジュール $\pi_{\text{new}}$ を統合した合成方策 $\pi_{\text{comp}}$ を過去タスク $\mathcal{T}_{\text{past}}$ に適用したときの物理実行軌跡 $\tau_{\text{comp}}$ は、更新前の旧合成方策による軌跡 $\tau_{\text{old}}$ と完全に一致する：
$$\tau_{\text{comp}} \equiv \tau_{\text{old}} \implies \text{SuccessRate}(\pi_{\text{comp}}, \mathcal{T}_{\text{past}}) = \text{SuccessRate}(\pi_{\text{old}}, \mathcal{T}_{\text{past}})$$

### 2.3 実装・実測上の限界と注意点
- **「ステップ数の一致」と「軌跡一致」の区別**:
  - 実験において過去タスクが同一ステップ数で成功したとしても、それ単独で「誤介入確率が厳密に 0 であること」や「全状態での軌跡一致」を数学的に証明したことにはならない。
- **ルーター再学習に伴う既存モジュール間境界の変動リスク**:
  - 新モジュール $\pi_{\text{new}}$ を追加してルーターを再学習（Fit）した場合、新モジュールが選ばれなくても、Base と既存 Place 間の決定境界がわずかに変化すれば、旧タスクの軌跡が分岐する可能性がある。
  - したがって、真の不変性を保証するには「ルーターの既存クラス間境界を歪めない制約付き学習」または「階層的ゲーティング」が理論的前提として要求される。

## 3. 命題 2：局所介入による蒸留誤差伝播の縮小上界（Bounded Error Propagation Under Local Composition）

### 3.1 前提仮定（Assumptions）
- **仮定 2.1（有限ホライズン）**: タスクは最大 $H$ ステップで終了する。
- **仮定 2.2（局所介入の発生）**: 合成方策の実行中、新モジュールが選択・介入する時刻 $t$ における確率を $\rho_t = P(R(s_t) = \text{new})$ とする。
- **仮定 2.3（局所判断不一致確率）**: 新モジュールが選択された局面において、軽量 Candidate CART $\pi_C$ が参照モデル（Temporaryまたは教師）$\pi_T$ と異なる行動を出力する条件付き確率（局所蒸留誤差）を $\epsilon_t = P(\pi_C(s_t) \neq \pi_T(s_t) \mid R(s_t) = \text{new})$ とする。

### 3.2 命題の主張（Proposition 2）
同一の Base 方策・同一ルーター・同一実行器のもとで、参照合成方策 $\pi_{\text{comp}}^T$ と Candidate 合成方策 $\pi_{\text{comp}}^C$ の物理実行軌跡が、時刻 $H$ までに少なくとも 1 回分岐する確率 $P(\tau_C \neq \tau_T)$ には、Union Bound による以下の保守的累積上界が存在する：
$$P(\tau_C \neq \tau_T) \le \min\left(1, \; \sum_{t=1}^H \rho_t \cdot \epsilon_t\right)$$

### 3.3 理論的解釈の厳密化（「直接Candidateの有効性」との関係）
- **積 $\sum \rho_t \epsilon_t$ の重要性**:
  - 上界の大きさは、単に介入率 $\rho_t$ が小さいこと（例: 介入率 2.2%）だけでは決まらない。例えば 19 回の介入があり、各ステップでの判断不一致確率 $\epsilon_t$ が仮に 5% だとすると、累積上界は $19 \times 0.05 = 0.95$ となり、上界としては極めて緩く実用的な性能維持の保証にはならない。
  - したがって、累積誤差を低く抑えるためには、**介入回数自体が抑制されていることと、介入時における局所判断誤差 $\epsilon_t$ が十分に小さいことの双方が不可欠**である。
- **直接Candidate方式へのインプリケーション**:
  - この式そのものは「Temporary MLP を省略して直接小型 CART を fit しても同等性能になる」ことを演繹的に証明するものではない。
  - 直接Candidate方式が成立するためには、「収集された局所データ分布において、直接 fit された小型 CART の判断誤差 $\epsilon_t$ が実用上十分に小さいこと」を別途実験的に示す必要がある。W5（T16）の実測結果は、特定タスク（水平運搬補正）においてその誤差が小さかったという個別実例であり、あらゆる局所補正において Temporary が不要であることを意味しない。

## 4. 命題 3：費用比較モデルと損益分岐の定式化（Breakeven Analysis Model）

### 4.1 費用モデルの定義
ある能力要求（Capability Requirement）が長期課題列において $n$ 回出現する環境を想定する。
- **APC（定着・再利用型）の総費用**:
  $$C_{\text{APC}}(n) = C_{\text{acq}} + C_{\text{cons}} + n \cdot C_{\text{use}}$$
  ここで、$C_{\text{acq}}$ は初回不足プローブ・探索・データ収集の総費用、$C_{\text{cons}}$ は Candidate 学習・検証・ルーター再学習の総費用、$C_{\text{use}}$ は各再出現時の推論・適用費用。
- **毎回再学習ベースライン（Relearning Baseline）の総費用**:
  出現ごとに同一規模の探索・再学習を行う場合：
  $$C_{\text{relearn\_total}}(n) = n \cdot C_{\text{relearn}}$$

### 4.2 損益分岐回数 $n^*$ の理論式
$C_{\text{relearn}} > C_{\text{use}}$（再学習費用が推論費用を上回る）という妥当な仮定のもとで、APC が毎回再学習ベースラインに対して累積費用で優位に立つための損益分岐回数は以下となる：
$$n^* = \frac{C_{\text{acq}} + C_{\text{cons}}}{C_{\text{relearn}} - C_{\text{use}}}$$

### 4.3 現時点での実測限界と過大主張の撤回
1. **初回獲得総費用の未測定**:
   - W7 実測において報告された「5.50秒」は、不足プローブ実行後に計測を開始したルーター再学習（DecisionTree fit）の時間のみである。
   - 運搬Candidate自体の探索・生成費用やプローブ環境ステップは含まれておらず、5.50秒を $C_{\text{acq}} + C_{\text{cons}}$（初回獲得総費用）とすることはできない。
2. **損益分岐 $n^* = 1$ の撤回**:
   - 分子・分母に不完全な費用（5.50秒）を代入して「1回の再出現で費用優位性が確定」と主張することは不適切であり、これを撤回する。
3. **競合方式（共有モデル＋リプレイ）の現実的挙動**:
   - 強い競合方式である「共有モデル＋リプレイ」は、既知課題の再出現ごとに必ずしも全体再学習を行うわけではない。
   - したがって、APC が共有モデル＋リプレイに対して真に費用優位性を持つかどうかは、**同一総計算予算・同等性能のもとでの直接対照実験を実施するまで未決着**として扱う。
