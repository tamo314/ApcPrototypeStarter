## 1. 目的と検証内容

複数モジュール（最下層 Base CART、把持回復 Grasp Guard、運搬局所補正 Transit Gate CART、配置局所パッチ Place CART）を合成してタスクを実行する際、単独モジュールの動作精度だけでなく、**モジュール間の入口条件（Entry Conditions）、出口分布（Exit Distribution）、引き継ぎ（Handover）、切替振動（Chattering）、行き止まり（Deadlock）**の挙動を明確に切り分ける必要がある。

本検証（W4 / T12）では、物理シミュレーションの実測軌跡データに基づき、4層モジュール間の境界と復帰ダイナミクスを定量的に分析・整理した。

## 4. 結論

1. **入口・出口の完全整合**:
   - 各モジュールの出口状態（把持完了、水平補正完了、目標到達）が、次モジュールまたは基盤方策の許容入力空間に完全に収まっており、モジュール間の隙間やオーバーラップによる破綻が存在しないことを実証した。
2. **状態非リセットの保証**:
   - モジュール切替時に物理状態や台車・腕の保持目標をリセットせず、連続的な指令値を保ったまま引き継ぎが成立している。
3. **統合ルーター（W4 / T13）への準備完了**:
   - 各モジュールの発動条件と引き継ぎ関係が明確に定式化されたため、T13（単一統合ルーターの学習）において、競合のない統一選択モデルの構築が可能となった。
