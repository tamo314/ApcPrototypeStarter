## 1. エグゼクティブサマリー（現在地と学術的総括）

本報告書は、`docs/APC_THEORY_VALIDATION_ROADMAP.md` に基づき、具現化AI（Embodied AI）における **Adaptive Primitive Consolidation (APC: 適応型プリミティブ統合)** アーキテクチャの妥当性・機構動作・物理的境界を物理シミュレータの実測データに基づき客観的に検証した中間総括である。

実験コードおよび物理ログの綿密な照合と検証を経て到達した現時点での学術的結論は、次の通りである：

> **「小型の局所モデル群による補正・選択・再利用の実行可能性は示されている。一方、新規獲得の継続閉ループ、独立した合成転移、費用優位性は検証中である。」**

### 1.1 実証された主要な到達点
1. **局所小型モデル群による補正・自律選択の実行可能性（W1–W4, W6）**:
   - 凍結された基盤方策（Base）に対し、水平運搬補正（CART 25ノード）および配置下降（CART 55ノード）を局所パッチとして組み合わせ、17ノードの学習決定木（Unified Router）により自律的にモジュールを切り替えてタスクを達成できる実行可能性を確認した。
2. **モデルファイル実行依存の切り離し（W3, W8 / T10, T25）**:
   - Temporary MLP や教師データ、オプティマイザを一切含まない、チェックポイント4点（合計 39,817 bytes、勾配パラメータ数 0）の最小配布物により、独立別プロセスでの課題実行を確認した。
3. **同一ルーターによる除去対照（W6 / T18）**:
   - 同一のルーターおよび Base を固定した厳密なアブレーション実験により、Transit および Place の各局所モジュールが特定課題の達成に寄与している因果関係を確認した。

### 1.2 明確化された限界・来歴重複・残存課題
1. **継続学習（W7）における適応の実態**:
   - W7 の実測ベンチマークは「課題列の中で未知の不足を自律検出し、新規データを収集して新しいCandidateを獲得する」閉ループではなく、**「既存の運搬Candidateを課題列の途中で追加し、ルーターを再学習した後、固定された過去課題で成功を維持できた」** という初期的な追加・保持の検証にとどまる。
   - 報告された 5.50 秒はプローブ後のルーター再学習費用のみであり、Candidate の初回獲得総費用ではない。また、共有モデル＋リプレイ等との同一総予算比較は未実施である。
2. **独立再現（T25）における学習来歴の重複**:
   - T25 で評価したシード群のうち、Place 3002、TruePlace 3010、TruePlace 3013 の 3 条件は `train_unified_router.py` の学習データに含まれていた。したがって、「開発過程で一度も参照されていない完全未使用条件」ではなく、ルーター学習歴を含む条件での再現性確認として扱う。
3. **失敗要因の個別性と未決着の境界**:
   - Seed 3014（Transit 不発による Base タイムアウト）と Seed 3013（Step 829 で Place 進入 $\to$ 終端ラッチ発動 $\to$ 偏差 2.4 cm でスタック・タイムアウト）は異なる物理メカニズムで失敗しており、同一の幾何外挿境界として一般化することはできない。系統的な境界掃引実験は今後の課題である。
4. **手設計回復ガードと終端配置ラッチへの依存**:
   - 低位の接触外乱からの復帰は手設計の状態機械（`GraspRecoveryGuardSelector`）に依存しており、また配置開始後は `latched_place` による不可逆ラッチが動作している。

## 4. 条件付き理論命題の検討と留意事項（W8: T23）

詳細は [`docs/APC_THEORY_CONDITIONAL_PROPOSITIONS.md`](file:///c:/Work/ApcPrototypeStarter/experiments/maniskill/docs/APC_THEORY_CONDITIONAL_PROPOSITIONS.md) を参照。

1. **命題 1（非介入領域における行動保持）**:
   - Base だけでなく「旧合成方策全体」および「既存モジュール間のルーティング決定境界」が不変であることが前提条件となる。新モジュール追加に伴うルーター再学習により既存クラス間境界が変動するリスクを考慮する必要がある。また、「同じ成功step数」単独では軌跡一致や誤介入ゼロは証明されない。
2. **命題 2（局所介入による蒸留誤差上界）**:
   - 累積誤差上界 $\min(1, \sum \rho_t \epsilon_t)$ は、介入率 $\rho_t$ だけでなく「介入回数 $\times$ 局所判断誤差 $\epsilon_t$」の積に依存する。この式自体は直接Candidateの有効性を保証するものではなく、別途直接 fit された小型 CART の誤差 $\epsilon_t$ が小さいことを実験的に示す必要がある。
3. **命題 3（費用モデルと損益分岐）**:
   - 理論式 $n^* = (C_{\text{acq}} + C_{\text{cons}}) / (C_{\text{relearn}} - C_{\text{use}})$ は妥当であるが、W7 実測の 5.50 秒は初回獲得総費用ではない。また共有モデル＋リプレイが毎回再学習するとは限らないため、実測比較としての損益分岐点は未確定である。

## 6. 次期検証計画（本当に必要な次のステップ）

視覚入力や多物体操作へ研究を広げる前に、現在の環境において以下の **厳密な検証サイクルを一本通すこと** を最優先課題とする：

1. **自律不足検出からの真の新規獲得閉ループ**:
   - 既存 Candidate のファイルコピーを完全に排除する。
   - 不足検出器の出力から実際に新規環境データをサンプリングし、直接 Candidate を獲得する処理を、異なる不足に対して **少なくとも 2 回** 連続して実施する。
2. **同一総予算のもとでの共有モデル＋リプレイとの直接比較**:
   - 同じ環境ステップ数・同一計算予算のもとで、単一モデル＋リプレイ方式と APC の保持率・タスク達成率・再適応費用を直接比較し、H8（資源上の利得）の真否を判定する。
3. **学習来歴から完全に独立した保留組合せの評価**:
   - 今回使用した 3010・3013・3014 などの開発・評価シードとは完全に独立した新規シード・新規配置において、未学習の能力組合せ転移（H6）を検証する。
