# APC「勝つ条件・負ける条件」の交互作用表と破綻境界分析（W8: T24）

作成日：2026-09-25（JST）  
対象タスク：W8 / T24（理論が予測する勝つ条件・負ける条件の対比、交互作用表、破綻境界の同定）  
対象命題：H6（合成転移の限界）、H8（資源利得の損益分岐）、H1（局所獲得の有効範囲）、H2（適用境界）

---

## 1. 目的と位置づけ

科学的理論の確立において最も重要な原則は、**「提唱するアーキテクチャが有利となる都合のよい条件だけを報告するのではなく、どのような条件下で利得が最大化され、どのような境界において破綻・劣化するか（反証可能性と成立境界）を厳密に同定すること」**である。

本稿（W8 / T24）では、W0〜W7 の物理シミュレーション実測データに基づき、APC が基準方式に対して明確に優位性を持つ「勝つ条件」と、ゼロショット合成が破綻したり利点が消失する「負ける条件（破綻境界）」を体系的な交互作用表（Interaction Matrix）として整理する。

## 3. 体系的交互作用表（Interaction Matrix）

| 環境要因 / 制御軸 | APC が勝つ条件（有利・成立領域） | APC が負ける・破綻する境界条件（制約・破綻領域） | 物理実測による根拠 | 基準方式（全体再学習・リプレイ等）との比較 |
|---|---|---|---|---|
| **1. 要求変化の空間局所性** | **局所分布内**（目標位置 $y \le 0.15\,\text{m}$）：<br/>Base が接近・把持を担い、運搬 CART（19 steps）と配置 CART（153 steps）がピンポイント介入 | **極端な外挿**（目標位置 $y > 0.20\,\text{m}$）：<br/>ルーターの入力特徴量が閾値を超えず、運搬モジュールが不発となり Base が停滞 | **Seed 3012（844 steps 成功） vs Seed 3014（1,200 steps 失敗）** | 全体再学習方式であれば 3014 でも長時間をかければ適応可能だが、APC の更新 0 合成は幾何境界で破綻する |
| **2. タスクの再出現頻度** | **高再出現**（$n \ge 2$）：<br/>初回遭遇で Candidate 登録・ルーター更新（5.50秒）を行った後、2回目以降の再遭遇費用が **0.0 秒（100% 削減）** | **完全使い捨て**（$n = 1$）：<br/>二度と現れない課題に対して Candidate 定着やルーター再学習を行うと、5.5 秒のオーバーヘッドが無駄になる | **W7 実測多タスク列（Block 3 で 5.5s、Block 4〜6 で 0.0s、損益分岐 $n^*=1$）** | 単発タスクでは即興の Temporary を使い捨てにするか直接行動を出力する方が低コスト |
| **3. 障害の階層レベル** | **下流・局所障害**（運搬不足・精密配置）：<br/>把持状態が安定しており、手先速度や姿勢の局所補正のみでゴール達成可能な局面 | **上流・身体的障害**（把持脱落・空振り）：<br/>指が開いたまま停滞する未把持や、把持高さ不足による滑落。局所運搬 CART では一切救済不能 | **Seed 3009（未把持 1,200s 失敗） $\to$ 手設計 GraspRecoveryGuard 導入で 819s 成功** | 上流の身体的失敗には低位の安全状態機械または高自由度プランナーが必要であり、学習パッチの限界を示す |
| **4. 作業列の循環性** | **順次 1 パス作業列**：<br/>接近 $\to$ 運搬 $\to$ 配置 $\to$ 静止。配置開始後に `latched_place` で終端ラッチし、確実な接地・指開きを完遂 | **多物体循環・反復作業**：<br/>物体 A を配置した後、物体 B を把持しに行く作業。現在の終端ラッチが解除されず、Base への復帰不能 | **T19（1 エピソード 844 steps 完遂）と `primitive_policy.py` のラッチ実装** | 循環作業を行うには、ラッチをタスク完了イベントで明示的にアンラッチする上位シーケンサーが必要 |
| **5. 観測空間の不変性** | **幾何観測整合**：<br/>ロボットのアーム自由度・関節配置・手先相対座標系（`geometry_features`）が固定されている環境 | **身体性・観測空間の改変**：<br/>自由度の変更、カメラ視点の変形、自由度欠損。既存プリミティブおよび特徴量 schema が無効化 | **命題 1 の前提仮定 1.1（観測変換の不変性）** | 身体表現自体の変更には、局所パッチではなく最下層 Base 方策の全体再学習が不可欠 |

## 4. 客観的洞察とアーキテクチャ設計指針

1. **APC の「スイートスポット（最適合領域）」**:
   - ロボットの基本身体能力（接近・把持）が既に存在し、環境や目標位置の局所的変動（運搬補正、精密配置）に繰り返し直面する産業用ピック＆プレースや流通ソーティングなどの環境。
   - この領域において、APC は超軽量な決定木（35.8 KB）としてパラメータ数 0 で運用でき、破滅的忘却 0% と再遭遇費用 100% 削減の利得を最大限に発揮する。
2. **APC を適用すべきでない領域**:
   - 毎回全く異なる一度限りのタスクが要求される環境（定着費用の償却不能）。
   - アーム自由度やセンサー配置が頻繁に変更される環境（表現不変性の破綻）。
   - 未把持やスリップなどの物理的破壊が頻発する極限環境（学習パッチよりも確定的安全ガードが優先されるべき領域）。
