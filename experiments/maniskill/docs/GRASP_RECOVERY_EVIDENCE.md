## 1. 背景と課題

先行実験において、未知配置シード群（3008–3013）の評価で以下の深刻な上流失敗が特定されていた：
- **seed 3009（未把持）**: 手先はキューブ直上 1.2 cm まで正確に下降したものの、Base CART が指を閉じるコマンド（`primitive 7: close_gripper`）を出力せず、`primitive 8: CONTINUE` を出力し続けて静止・停滞し、1200 steps を通じて把持率 0% で失敗した。
- **seed 3008（把持脱落・滑落）**: Step 563 で把持したものの、把持高さが浅く（`hand_z = 0.045 m`）、持ち上げ時の水平移動（Step 587, 606）でキューブが滑落。キューブが机上に置き去りになった後、グリッパーが閉じたまま空中で静止し、再把持不能に陥った。

これらは運搬層や配置層の問題ではなく、**把持層（Layer 1）における判断不足と回復能力の欠如**によるものであった。

## 2. 把持回復モジュール（Grasp Recovery Guard）の設計と実装（T06）

既存の 20 身体性プリミティブ（IK/PD実行器）をそのまま用い、凍結された Base CART の判断不足を補う最小局所パッチ `GraspRecoveryGuardSelector` を設計・実装した。

### 2.1 介入条件と回復アルゴリズム
1. **未把持救済（Missed Grasp Rescue）**:
   - **発動条件**: 手先がキューブ把持ゾーン（$d_{xy} < 0.012\,\text{m}, |d_z| < 0.010\,\text{m}$）に到達しており、指が開いている（`gripper_target >= 0`）にもかかわらず、Base CART が下降（5）も閉指（7）も出さず停滞（`raw_id not in (5, 7)`）している場合。
   - **行動**: `primitive 7: close_gripper` を出力し、把持を確実に成立させる。
   - **正常系への非干渉**: Base CART が正常に下降している最中（`raw_id == 5`）には絶対に割り込まず、下降完了後の停滞のみをピンポイントで救済する。
2. **把持脱落回復（Lost Grasp Recovery Cycle）**:
   - **発動条件**: キューブが把持されておらず（`grasped == False`）、グリッパーが閉じた状態（`gripper_target < 0`）が 15 steps 以上継続し、かつキューブが机上（$z < z_{\text{init}} + 0.03\,\text{m}$）にある場合。
   - **復帰シーケンス**:
     1. **開指（Opening）**: `primitive 6: open_gripper` で指を開く。
     2. **退避上昇（Clearing）**: 手先がキューブ上空（$z < z_{\text{cube}} + 0.08\,\text{m}$）に達するまで `primitive 4: hand_z_plus` で上昇。
     3. **水平整合（Aligning）**: キューブの滑落位置の真上（$d_{xy} \le 0.008\,\text{m}$）へ手先を水平移動（$\pm X: 0, 1 / \pm Y: 2, 3$）。
     4. **再下降（Descending）**: キューブ把持高さまで `primitive 5: hand_z_minus` で下降。
     5. **再把持（Re-grasping）**: 把持ゾーン到達で `primitive 7: close_gripper` を出力し、把持を再成立させて運搬フェーズへ復帰。

## 4. 客観的知見と理論的インプリケーション

1. **上流層の不足解消によるパイプライン導通**:
   - seed 3009（未把持）および seed 3008（把持脱落）において、把持層の局所パッチにより 100% 把持を成立・復帰させ、後続の運搬・配置フェーズへの引き渡しを達成した。
2. **正常系に対する副作用ゼロ（Zero-Regression）の達成**:
   - 未把持救済を「Base CART の停滞（`raw_id not in (5, 7)`）」に厳密に限定したことで、正常な下降・閉指を行う seed 3011 に対する誤介入を完全に排除した。
   - その結果、seed 3011 は旧記録（895 steps）を上回る **819 steps で連続 20 steps 安定維持を達成**し、既存能力を一切毀損しないことが実証された。
3. **多層合成（Layered Composition）の実証**:
   - 最下層（Base CART）、把持層（Grasp Recovery Guard）、運搬層（Transit Guard CART）、配置層（Place Patch CART）の4層が、同一の 20 身体性プリミティブ空間の中で互いに干渉せず、物理的に完全に調和して動作することを確認した。

> [!NOTE] 機構上の位置付けに関する客観的明記
> 本実験の `GraspRecoveryGuardSelector` は、状態を監視して開指・退避上昇・水平整合・再下降・閉指を行う手設計の状態機械（安全・救済レイヤー）である。これは上流失敗の原因を物理的に切り分け、把持回復可能性を実証するための有用な機構であるが、「回復 Temporary を学習して自律獲得した成果」ではない。安全制約や確定的な復帰処理としての役割と、学習によって獲得される適応能力を明確に区別して位置付ける。
