## 1. 目的と実施内容

本タスク（T27）は、Phase W0〜W8 の中間総括を踏まえ、新能力の真の獲得・継続保持・費用比較サイクル（T27〜T44）を開始するための **「追跡可能な最小比較仕様の固定」** を目的として実施した。

以下の 4 成果物を整備し、実実行を通じて検証した：
1. **初期資産マニフェスト（`configs/t27_initial_assets_manifest.json`）**:
   - 継承する Base、既存 Candidate（Place, Transit）、ルーター、共有安全層（`GraspRecoveryGuardSelector`）、および特徴スキーマの SHA256 とパラメータ仕様を確定。
2. **条件分割マニフェスト（`configs/t27_condition_split_manifest.json`）**:
   - 既知開発条件（既知成功・既知失敗）、新規獲得用探索候補（不足A・不足B）、および保留評価組合せを明確に分離。
3. **費用台帳（Cost Ledger）の自動生成機能（`scripts/run_t27_cost_ledger_pilot.py`）**:
   - 通常実行ステップ数、追加適応ステップ数、推論・実行時間、適応学習時間、モデルファイル容量を自動集計するパイプラインを構築。
4. **最小パイロット run の実走（`runs/apc-t27-pilot-20260925-a/`）**:
   - 既知課題（Pick 3201, Place 3001）と既知失敗（TruePlace 3014）の 3 エピソードを実行し、事前予測と実測結果の一致および費用台帳の自動出力を確認。
