4. **旧Aの独立4群の合算**（T49・T54・T59・T63、計340条件）：初期178 → 旧A 187。得15・失6、符号検定p=0.078。

**解釈**

- 旧A（5行・7ノードのCandidate）が、分析群でも最終群でも最も良かった。
  - 行を増やす（36行）ことも、成功した行だけに絞る（17行）ことも、改善しなかった。
  - 分析群では、成功行のみの版は旧Aより有意に悪かった（p=0.013、複数比較のうちの1つ）。
- 差は、同じ起動状態でCandidateが選ぶ選択肢から生じている。旧Aは回転・水平移動を選び、新しいCandidateは+z・−yを繰り返した。
- 解釈（推測）：獲得時の決定点の状態分布と、配備時にルーターが起動する状態分布がずれている。探索が選んだ「その条件で最良の選択肢」を浅い木で一般化すると、配備時の状態では別の選択肢に分岐してしまう。行が少なく木が小さい旧Aは、結果として少数の選択肢を返す単純な方策になり、それが当たっていたと考える。
- 旧Aの効果は、独立340条件で方向としては一貫している（得15・失6）。ただしp=0.078で、事前規則上は「差を検出できない」。
