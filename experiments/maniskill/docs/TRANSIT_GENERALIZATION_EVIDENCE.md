## 1. 実験目的と課題設定

旧運搬データセット（`20260925-b`）を用いた評価では、seed 3011（`-Y` 方向の補正が必要な課題）においてモデルが 1200 steps で停滞・失敗していた。
本実験群では、以下の要因を厳密に切り分けて検証した：
1. **T02（介入範囲の効果確認）**: 同一保存状態での判断分岐と局所介入の効果
2. **T03（多方向局所データの収集）**: 欠落していた `-Y`（`primitive 3`）を含む `±X, ±Y, ±Z, CONTINUE` の全方向局所データセット（`dataset-transit-teacher-20260925-d`）の構築
3. **T04（担当範囲×データの交互作用）**: 広域介入 vs 限定介入 × 旧データ vs 拡張データ の 2×2 因果検証
4. **T08（直接Candidate CARTとTemporary MLPの公平比較）**: 同一教師データから学習した直接 CART と MLP の性能・容量・安定性の比較

新プロトコル `HoldContinuousSuccess`（連続20 steps成功維持）の下で、同一の初期状態（seed 3011）、同一のBase CART、同一の配置パッチ CART を用いて比較した。

## 4. 客観的知見と理論的インプリケーション

1. **データ不足とスコープ限定の直交的寄与の実証**:
   - データ不足の解消（`-Y` の追加）は必須条件であり、旧データでは限定介入でも 3.93 cm で停滞していた問題が、新データによって 895 steps での完全成功へと解消された。
   - 一方で、CART のような小型モデルでは、データが存在していても広域介入（`cart_continuous`）では失敗し、**介入範囲を限定（`cart_guarded`）した瞬間に 895 steps で完全成功**した。
2. **Temporary MLP と 直接 Candidate CART の公平比較（T08）**:
   - 限定介入下において、Temporary MLP（11,092 params）と直接 Candidate CART（25 nodes, 600 stored values = 0 勾配params）は、**同一の 895 steps、同一の最小距離（0.0097 m）、同一の連続20 step維持を達成**した。
   - これにより、運搬局所補正においては、適切な限定介入スコープさえ与えられれば、**直接 Candidate CART を学習することで Temporary 経由と全く同等の性能を達成できること**が実証された。
