# Project Roadmap

## Stage 0 — Environment and reproducibility
Outcome: one-command test/smoke workflow on the target PC.

## Stage 1 — Static compositional substrate
Outcome: stable core + primitive bank solves known tasks and some held-out compositions.

## Stage 2 — Selective plasticity
Outcome: controller distinguishes composition-search failures from genuine novel-operation failures well enough to avoid expanding on most familiar/compositional events.

## Stage 3 — Consolidation loop
Outcome: novel operation is learned in temporary capacity, compressed, shadow-validated and retained after temporary resource release.

## Stage 4 — Repeated lifelong cycle
Outcome: at least two novel operations are learned in sequence while earlier skills are retained and reused.

## Stage 5 — Learned resource control
Outcome: replace some hand-set thresholds with a constrained learned controller only if Phase A signals are predictive and stable.

## Stage 6 — Multi-timescale plasticity
Outcome: candidate, stable and meta parameters update at intentionally different timescales.

## Stage 7 — Small pretrained LM transfer
Outcome: reproduce the loop on a 0.5B–2B pretrained LM using parameter-efficient adaptation on the 16GB GPU.

## Stage 8 — Memory/computation split
Outcome: route factual/episodic information to memory and reusable transformations to the primitive bank.

## Stage 9 — Dense-teacher primitive extraction
Outcome: test whether useful primitive modules can be discovered from an independently trained dense teacher and transplanted into APC.

## Stage gates

Do not advance because a component merely runs. Advance only when the current stage has a measurable result against its baseline.
