# Conditional Neural Primitives — CNP研究方針

日付: 2026-09-21 / 計画タスク: CNP-000 / 決定: ADR-0187

状態: `DESIGN_BASELINE_RECORDED`。ユーザーが採用した方向性を具体化した計画であり、
実装・訓練・確認実験の完了記録ではない。この依頼の実施範囲は計画立案まで。
後続の実装・研究実行指示は[実装計画](../exec-plans/active/CONDITIONAL_NEURAL_PRIMITIVES.md)の
タスクIDと範囲で扱う。計画作成を、全段階の自動実行やsealedアクセスの許可に読み替えない。

## 1. 研究の問い

**条件に応じて振る舞いを変える小型NNを一つの再利用可能な技能として保持し、
その局所的な追加学習を、既存能力を保ちながら複数の用途へ波及させられるか。**

最初の対象は `CONDITIONAL_SELECT` 一種類。対象要素の位置を渡すSELECTとは異なり、
見本ベクトルと閾値を引数とし、各要素を選ぶかをNNが計算する。
操作数を増やすことやNNを大きくすることを成功条件にしない。

| 仮説 | 判定対象 | この仮説だけでは主張しないこと |
|---|---|---|
| H-CNP1 条件間再利用 | 同一重みが未学習の見本・閾値の組み合わせで選択できる | 未知の操作を発見した、APC全体が通常NNより優れる |
| H-CNP2 局所適応と保持 | 共有基盤を凍結した小さな追加重みで新しい条件域へ適応し、旧条件を保持する | 一時大容量化や蒸留の必要性 |
| H-CNP3 実行への波及 | 単体学習だけの更新が、直接訓練していない連続合成でも有効になる | 潜在プログラムの発見、複数のNN技能の自律的な協調 |
| H-CNP4 費用上の価値 | 同等の精度・保持条件で、比較方式より総費用または保存容量を節約する | 更新パラメータが少ないだけで高速・安価という結論 |

H-CNP1は技術成立性、H-CNP2/3は転移機構、H-CNP4は採用価値であり、別々に報告する。
一種類のNNだけの段階では、通常の条件付きNNとAPCの選択部品は同じモデルになり得る。
その比較を異なる二方式として数えず、モジュール化の優位性を主張しない。

## 2. 既存研究との関係

- 現行プリミティブは既にNNである。変更点は条件に対する学習範囲、連続値の入出力契約、
  追加学習と検証の単位である。
- [Phase B終端](../exec-plans/active/PHASE_B_RESTART.md)、Phase C終端、
  [D-017監査](EVIDENCE_INTEGRITY_AUDIT_D017.md)による既存結果の解釈を変更しない。
- D-013のH-D1 `REFUTED` は保存する。REVERSE/SELECTの短系列欠損を
  「NN技能は不可能」と一般化しない。合成が作る入力域を評価に含める根拠とする。
- [H-D2/D-018](PHASE_D_RESEARCH_CHARTER.md)は独立した既存契約。
  CNPの前提実験ではなく、CNP開始によって実行・取消・変更されたことにもならない。
- Phase Dの `population=exhaustive` と乱数生成の不一致は既存コード上の懸念として保存する。
  CNPはその評価器を流用しない。過去の数値を全列挙性能として引用しない。

新しいデータ・小型モデルを独立した名前空間で構築する。旧bundleの変換や復旧を
CNPの準備条件にしない。既存sealed領域は読まず、生成器やモデルを再利用しない。

## 3. 採用する構成

```
入力集合 -> 固定されたタスク非依存Encoder -> 選択された条件付きNN -> 予測マスク
                                              ^                    |
見本・閾値 -> 型検査済みPrimitiveCall.arguments --+                    v
                                                        共通形式の中間集合
                                                                |
                                                        次の明示的な呼び出し
```

Coreはまず固定の特徴変換のみとし、学習による情報不足や表現の変化を切り離す。
見本・閾値はプリミティブにのみ渡す。出力件数を正解から与えない。
初回は明示的な呼び出し順を使い、ルータ学習、少数例からの意図推定、役割の自動発見は
研究変数に含めない。少数のラベル付き例は「適応用教師」であり、未知意図の推定ではない。

[詳細設計](../design-docs/CONDITIONAL_NEURAL_PRIMITIVES.md)を実装仕様の正本とする。
初期方式は小型NNの直接学習、その後は安定重みを凍結した残差adapter。
一時大容量教師、hypernetwork、RL、事前学習LM、構造探索は初期計画に含めない。

## 4. 比較の考え方

最初の問題は、公開された非線形特徴上の未知の距離尺度による条件付き選択である。
ラベルを作る内部行列は生成・参照実行側だけが持つ。全ての通常方式には同じ観測・引数・
教師ラベルを渡す。数学的な解法が存在することを失敗条件にせず、費用と再利用を測る。

必須比較は、未学習のユークリッド距離、学習するPSD距離尺度、通常の条件付きNN、
適応時の全重み更新＋同量リプレイ、全重み更新のみ、タスク別直接学習。
正解生成器を知る記号参照は完全性の上限・評価器の制御であり、同情報の学習方式とは区別する。
公開された仕様だけから同情報・低費用の厳密解法が実装できた場合は比較対象に追加し、隠さない。

この合成問題はNNに有利であることを保証しない。距離尺度学習に負けた場合も有効な結果である。
まずこの問題で測定系を成立させ、NNを有利に見せるために生成器を結果後に複雑化しない。

## 5. 実施順と判断

1. CNP-001: 入出力、生成器、独立参照、分割、情報境界、baseline、評価器を実装・テスト。
2. CNP-002: 固定予算・開発seedだけで技術成立性と実測費用を確認。閾値緩和や自動再試行なし。
3. CNP-003: 未使用条件・5反復でH-CNP1を確認。確認前にコード・設定・分割を固定。
4. CNP-004: H-CNP1成立後、条件域を順に追加し、H-CNP2/3/4を同じ情報・予算で比較。
5. CNP-005: 保存証拠から採否判断。必要性を示した場合のみ複数NN技能や例からの条件推定を設計。

詳細な閾値、件数、上限、停止理由は[実装計画](../exec-plans/active/CONDITIONAL_NEURAL_PRIMITIVES.md)
で固定する。初期数値は既存結果から推定した性能ではなく、2026-09-21に選んだ実用目標である。

| 結果 | 判断 |
|---|---|
| データ・評価器・情報境界に欠陥 | `INVALID_EVIDENCE`。仮説の否定に数えず、依存する実験を停止 |
| 条件付き実行が成立しない | H-CNP1不支持。この構成・予算の限界を記録し、適応段階へ進まない |
| H-CNP1のみ成立 | 条件付き小型NNとしての成果。継続学習やAPC優位性の証明ではない |
| 局所適応・保持・合成波及が成立するが費用利益なし | 機構上の成果に限定。追加の複雑化を標準採用しない |
| 同等品質で総費用または保存量に事前基準以上の利益 | 対象範囲を明示して次段階の設計へ進む |
| 単純な方式に支配される | この領域では単純な方式を推奨。NNの必要性を前提に研究を拡大しない |

## 6. 将来段階の位置づけ

以下は実行待ちタスクではなく、CNP-005で必要性を判定する候補。

- **複数NN技能:** `CONDITIONAL_MATCH` など、SELECTと異なる出力・計算を持つ部品を追加。
  NN同士の合成と、全体モデル＋リプレイの比較はここで初めて本格的に扱う。
- **少数例からの条件表現:** 明示引数を隠す情報条件を別途定義し、識別可能性と
  同じ例を使う最小二乗・距離学習等を先に確認する。既存Phase B/Cの再開とはしない。
- **定着・圧縮:** adapterの増加や推論費用が問題になった場合に、複製候補への統合を比較。
  直接学習に加えて蒸留・検証まで含めた費用を計測する。
- **役割の自動発見:** 部品の実行と再利用に利益が出た後の独立研究。

## 7. 計画の根拠

- [研究実行規則](../RESEARCH_EXECUTION_RULES.md)と
  [因果的プリミティブ設計](../design-docs/CAUSAL_PRIMITIVE_EXECUTION.md)の内容／条件分離、
  選択部品だけの実行、候補の分離、参照対照、保存証拠を継承する。
- 旧規則中のPhase B固有の実験表への参照は、CNPの承認・合格を意味しない。
  CNPの判断基準はこの契約とリンク先で独立に定義し、旧研究ゲートを置換しない。
- [Modular meta-learning](https://arxiv.org/abs/1806.10166): 学習済みNN部品の再構成という先例。
- [Continual Learning via Local Module Composition](https://arxiv.org/abs/2111.07736):
  部品の選択・追加・合成と、候補増加による選択の難しさという先例。

両論文は設計上の参考であり、CNPの性能、費用利益、外挿性能の証拠ではない。
