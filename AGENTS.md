# AGENTS.md

APC is a research repository. Preserve historical code, measurements, user changes,
and existing run directories. Do not fabricate execution, metrics, or artifacts.

## Select the working rules before acting

- **ManiSkill / embodied APC research:** read
  [experiments/maniskill/AGENTS.md](experiments/maniskill/AGENTS.md), then that
  workspace's README and the relevant section of its research plan. This is the
  experiment-first track authorized on 2026-09-22. It has no phase STOP GATES,
  mandatory ADR chain, sealed-set prerequisite, or repository-wide test requirement.
  It permits RL/IL for the embodied experiment and uses its own Python environment.
  Its rules also govern root documentation edits made solely to support this track.
- **Existing synthetic APC / Phase A–C / NRQ / CNP work:** follow
  [AGENTS_LEGACY.md](AGENTS_LEGACY.md), preserved byte-for-byte from the former
  root guide. The new track does not reopen, reinterpret, or erase historical work.
- Mixed changes: keep the tracks isolated; legacy rules apply only to the legacy
  files/experiments actually changed, not as prerequisites for ManiSkill research.

For the new research entry point, see [MANISKILL.md](MANISKILL.md).
